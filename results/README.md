# Evaluation Metrics & Visual Artifacts

This directory stores diagnostic evaluation reports, confusion matrices, training history curves, and comparative metrics generated by the training and evaluation pipelines.

---

## Generated Artifacts

1. **`confusion_matrix.png`**  
   Annotated 5x5 confusion matrix heatmap displaying absolute sample counts and normalized recall percentages across all Diabetic Retinopathy severity stages.

2. **`training_history.png`**  
   Dual-subplot figure illustrating Training vs. Validation Accuracy and Loss curves across Phase 1 (Frozen feature extraction) and Phase 2 (Fine-tuning).

3. **`class_distribution.png`**  
   Bar chart detailing sample counts for each clinical class across Train, Validation, and Test splits to document dataset balance.

4. **`evaluation_report.png`**  
   Summary report card card summarizing Accuracy, Macro Precision, Macro Recall, Macro F1-Score, and Macro ROC-AUC.

5. **`roc_curves.png`**  
   Multi-class One-vs-Rest (OvR) Receiver Operating Characteristic curves with individual class AUC metrics and Macro-average AUC.

6. **`metrics.json`**  
   Machine-readable JSON export of all evaluation metrics and classification report details.

7. **`model_comparison.json`**  
   Comparison records across candidate architectures (MobileNetV2, EfficientNetB0, ResNet50, VGG16, Custom CNN). Architectures not yet evaluated are marked as `"Not trained"`.

---

## Generating Results

Artifacts are automatically rendered upon running:
```bash
python src/train.py --model MobileNetV2
```
or directly evaluating an existing checkpoint via:
```bash
python src/evaluate.py
```
